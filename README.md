# GenClip – Chrome Extension สร้างคลิปขายเสื้อผ้าอัตโนมัติ

ใส่รูปสินค้าจริง แล้วระบบจะ
1. ส่งรูปให้ **ChatGPT** วางแผนคลิปเป็นฉาก ๆ พร้อมเขียน image prompt, video prompt และบทพูดภาษาไทย
2. ให้ ChatGPT **สร้างภาพเฟรมแรก** ของแต่ละฉาก โดยใช้ลายผ้าจากรูปจริง
3. ส่งภาพและ prompt ไปที่ **Google Flow** (โหมด Frames to Video) เพื่อสร้างวิดีโอฉากละประมาณ 8 วินาที
4. บันทึกไฟล์ทั้งหมดไว้ที่ `Downloads/GenClip/<ชื่อสินค้า>_<วันเวลา>/`

```
script.txt      บทพูด + prompt + แคปชัน + แฮชแท็ก
scene-01.png    ภาพเฟรมแรกของฉาก
scene-01.mp4    วิดีโอของฉาก
...
```

## ติดตั้ง
1. เปิด `chrome://extensions`
2. เปิด **Developer mode** (มุมขวาบน)
3. กด **Load unpacked** แล้วเลือกโฟลเดอร์ `D:\GenClip`
4. ปักหมุดไอคอน GenClip ไว้ แล้วคลิกเพื่อเปิด side panel

## เตรียมก่อนใช้
- ล็อกอิน **chatgpt.com** ด้วยบัญชีที่สร้างภาพได้ (แนะนำ Plus ขึ้นไป)
- ล็อกอิน **flow.google.com** แล้ว **เปิดโปรเจกต์ไว้หนึ่งโปรเจกต์** ในแท็บเดียวกับหน้าต่างที่ใช้งาน
- ตั้งค่าใน Flow ครั้งเดียว: สัดส่วน **แนวตั้ง 9:16**, จำนวน output **1 ต่อ prompt**, เลือกโมเดลที่ต้องการ (เช่น Veo 3 Fast เพื่อประหยัดเครดิต)
- ใน Chrome ให้ปิด "ถามตำแหน่งที่จะบันทึกไฟล์ทุกครั้ง" ระบบจะได้ดาวน์โหลดไฟล์ต่อเนื่องได้

## วิธีใช้
1. เพิ่มสินค้า ทำได้ 2 วิธี (ใส่ได้หลายสินค้า)
   - **ดึงจาก TikTok:** เปิดหน้าแก้ไขสินค้าใน Seller Center (`seller-th.tiktok.com/product/edit/...`) หรือหน้าสินค้าในร้าน แล้วกด **ดึงสินค้าจากแท็บ TikTok ที่เปิดอยู่** ระบบจะกรอกชื่อ ราคา และรายละเอียด และแสดงรูปทั้งหมดให้คลิกเลือก ถ้าข้อมูลไม่ครบ ให้สลับแท็บหรือเลื่อนหน้าใน Seller Center แล้วกดดึงซ้ำ ระบบจะเติมเฉพาะช่องที่ยังว่าง
   - **กรอกเอง:** ใส่ชื่อสินค้า ประเภท และรายละเอียด แล้วเลือกรูปจากเครื่อง
   
   เลือกรูปที่เห็นลายผ้าชัด 1–10 รูป แล้วกด **เพิ่มเข้าคิว**
2. กด **เริ่มทำงาน** แล้วเปิด side panel ค้างไว้ ระบบจะสลับแท็บ ChatGPT ↔ Flow ให้เอง
3. ถ้าระบบทำขั้นไหนอัตโนมัติไม่ได้ (เช่น หน้าเว็บเปลี่ยน) จะมี **แถบสีเข้มขึ้นบนหน้าเว็บ** บอกว่าต้องทำอะไร ให้ทำเองแล้วกด **ทำต่อ**
4. **รวมคลิป:** ระบบเก็บไฟล์วิดีโอของทุกฉากไว้ใน extension เมื่อครบทุกฉาก (แม้จะทำเสร็จต่างรอบกัน) จะรวมให้เองแล้วบันทึกเป็น `<ชื่อสินค้า>_<วันเวลา>.mp4` ในโฟลเดอร์ที่เลือกด้วยปุ่ม 📁 (เช่น `D:ClipGenClipFinal`) ถ้ายังไม่ได้เลือกหรือยังไม่ได้อนุญาต จะบันทึกที่ `Downloads/ClipFinal/` แทน กด 🎬 ในคิวเพื่อรวมใหม่ได้ ถ้าบางฉากไม่มีไฟล์เก็บไว้ ให้กด **"รวมคลิปเป็นไฟล์เดียว"** แล้วเลือกไฟล์ `scene-01.mp4`, `scene-02.mp4`, … ระบบจะเรียงตามชื่อไฟล์ การรวมใช้เวลาเท่ากับความยาวคลิป และต้องเปิด side panel ค้างไว้
   ถ้าต้องการรวมแบบไม่อัดใหม่ (ต้องมี ffmpeg):
   ```powershell
   powershell -ExecutionPolicy Bypass -File D:\GenClip\tools\concat.ps1 "$env:USERPROFILE\Downloads\GenClip\<โฟลเดอร์สินค้า>"
   ```

ติ๊ก **"สร้างแค่ภาพกับ prompt"** ถ้าอยากตรวจภาพก่อน แล้วค่อยนำ prompt ใน `script.txt` ไปสร้างวิดีโอใน Flow เอง

## ทำคลิปให้ไม่ซ้ำและเหมือนคนจริง
- **สไตล์คลิป** (ในฟอร์มเพิ่มสินค้า) มี 18 แบบ: แม่ค้าคุยเก่ง, ลองใส่โชว์ทรง, โชว์เนื้อผ้าใกล้ ๆ, ใส่ไปงานจริง, รีวิวแบบลูกค้า, โปรแรง, ก่อน/หลังใส่, 3 เหตุผลที่ต้องมี, ตอบคำถามลูกค้า, มิกซ์แอนด์แมตช์, แกะกล่อง, หน้าร้าน, ถ่ายนอกสถานที่, แนะนำไซส์, คู่หูรีวิว, ASMR เสียงผ้า, นับถอยหลัง และโฆษณามืออาชีพ ค่าเริ่มต้นคือ "สุ่มสไตล์ที่ไม่ซ้ำ" ระบบจำว่าสินค้าชื่อนี้เคยใช้สไตล์และบทเปิดแบบไหน แล้วสั่ง ChatGPT ให้คิดใหม่ไม่ซ้ำ ถ้าอยากได้คลิปใหม่ของสินค้าเดิม ให้เพิ่มเข้าคิวอีกครั้ง หรือกด ⟲
- **องค์ประกอบคลิป**: ทุกคลิปจะสุ่มสถานที่ ผู้นำเสนอ บทเปิด 3 วินาทีแรก มุมกล้อง และแสง/บรรยากาศ โดยไม่ซ้ำกับ 3 คลิปล่าสุดของสินค้านั้น
- **ตัวหนังสือแบบโฆษณามืออาชีพ** (หน้าตั้งค่า ใช้ 2 แบบร่วมกัน):
  - ChatGPT ใส่หัวข้อภาษาไทยในภาพแบบโปสเตอร์ (ป้ายชมพูขอบทอง ส่วนบนของภาพ) และสั่ง Flow ให้ตัวหนังสืออยู่นิ่ง ไม่เพี้ยน
  - ตอนรวมคลิป ระบบเขียนทับ ราคา, ป้ายโปรโมชัน, ปุ่ม "กดตะกร้าสั่งซื้อได้เลย" และชื่อเว็บในฉากสุดท้าย (ฟอนต์ Kanit สะกดถูกแน่นอน มีเด้งเข้า) และอัดคลิปที่ 1080x1920
  - ราคาและโปรกรอกในฟอร์มเพิ่มสินค้า (ราคาว่าง = ดึงจาก "ราคา ... บาท" ในรายละเอียด)
- **ชุดคู่จากเว็บร้าน** (หน้าตั้งค่า, ค่าเริ่มต้นเปิด): ถ้าสินค้าเป็นเสื้อ ระบบดึงผ้าถุง/กระโปรงที่มีของจาก nichapainnovation.co.th ถ้าเป็นผ้าถุง/กระโปรงจะดึงเสื้อ ChatGPT เลือกแบบและสีที่เข้ากัน แล้วแนบรูปชุดคู่สีนั้นตอนสร้างภาพ ผู้นำเสนอจึงสวมชุดคู่เดียวกันทุกฉาก (ชื่อชุดคู่จะอยู่ใน script.txt)
- **ความเร็วคลิป** (หน้าตั้งค่า): ค่าเริ่มต้น 1.15 เท่า ใช้ตอนรวมคลิป เสียงไม่แหลม คลิปจะสั้นลงตามสัดส่วน
- **ความเป็นมนุษย์ของผู้นำเสนอ** (หน้าตั้งค่า): แนวทางให้พูดเป็นกันเอง พูดต่อเนื่อง และเปลี่ยนสีหน้าหรือท่ามือตลอด แก้ให้เข้ากับร้านได้

## โพสต์ TikTok (กึ่งอัตโนมัติ)
หลังรวมคลิปเสร็จ ระบบจะเปิดแท็บใหม่ที่ TikTok Studio (`tiktok.com/tiktokstudio/upload`) แล้ว
1. แนบคลิปที่รวมแล้ว
2. ใส่แคปชันและแฮชแท็กจากแผนของ ChatGPT
3. เปิดป้าย **"เนื้อหาที่สร้างโดย AI"**
4. รอจนอัปโหลดเสร็จ แล้ว**หยุดให้คุณตรวจและกด "โพสต์" เอง** ระบบไม่กดโพสต์ให้

ต้องล็อกอิน TikTok ในเบราว์เซอร์นี้ไว้ก่อน กด 📤 ในคิวเพื่อเตรียมโพสต์ซ้ำได้ ปิดการเปิดอัตโนมัติได้ในหน้าตั้งค่า หัวข้อ "โพสต์ TikTok"

## โพสต์ Reels ลงเพจ Facebook
หลังโพสต์ TikTok ระบบจะเปิดหน้าสร้างรีลใน Meta Business Suite (`business.facebook.com/latest/reels_composer`) แล้ว
1. แนบคลิปที่รวมแล้ว และใส่คำอธิบาย + แฮชแท็กเดียวกับ TikTok
2. เปิดป้าย AI (ถ้าหน้านั้นมีตัวเลือก)
3. กด "ถัดไป" จนถึงขั้นแชร์ แล้วเลือก "แชร์ทันที" หรือ "กำหนดเวลา" (เวลาสุ่มแยกจาก TikTok)
4. กดแชร์ให้อัตโนมัติเมื่อทุกขั้นผ่าน (ปิดได้ในหน้าตั้งค่า)

ต้องล็อกอิน Facebook ที่เป็นแอดมินเพจในเบราว์เซอร์นี้ไว้ก่อน ถ้ามีหลายเพจ ให้เปิด Business Suite เลือกเพจ กดสร้างรีล แล้วคัดลอกลิงก์ (ที่มี `asset_id=`) ไปวางในหน้าตั้งค่า หัวข้อ "โพสต์ Reels ลงเพจ Facebook" กด 📘 ในคิวเพื่อโพสต์ซ้ำได้

## ปรับแต่ง
หน้า **ตั้งค่า** (ลิงก์มุมบนของ side panel)
- แก้ prompt วางแผนคลิปและ prompt สร้างภาพได้ เช่น เปลี่ยนโทนการพูด ฉาก หรืออายุผู้นำเสนอ
- เพิ่มข้อความต่อท้าย video prompt ทุกฉาก
- **Selector สำรอง**: ถ้า ChatGPT หรือ Flow เปลี่ยนหน้าตาจนระบบหาปุ่มไม่เจอ ให้ใส่ CSS selector ใหม่ที่นี่ (ดูชื่อคีย์ได้ใน `content/chatgpt.js` และ `content/flow.js`)

## โครงสร้างไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `sidepanel/sidepanel.js` | ตัวควบคุมลำดับงานทั้งหมด จัดคิว และดาวน์โหลดไฟล์ |
| `content/chatgpt.js` | แนบรูป พิมพ์ ส่ง รอคำตอบ และดึงภาพบน chatgpt.com |
| `content/flow.js` | เลือกโหมด อัปโหลดเฟรม ใส่ prompt กดสร้าง และรอวิดีโอบน Flow |
| `content/fb-post.js` | แนบคลิป ใส่คำอธิบาย ตั้งเวลา และแชร์รีลใน Meta Business Suite |
| `content/common.js` | ฟังก์ชันช่วย และแถบขอความช่วยเหลือ "ทำต่อ" |
| `lib/prompts.js` | prompt, สไตล์คลิป, องค์ประกอบคลิป และค่าตั้งต้น |
| `lib/overlay.js` | ตัวหนังสือที่เขียนทับตอนรวมคลิป (ฟอนต์ใน `assets/fonts`) |
| `lib/catalog.js` | ดึงสินค้าชุดคู่ที่มีของจากเว็บร้าน |

## ใช้ในทีม แบบง่าย (ไม่ต้องมีบัญชีอะไร)
1. ดาวน์โหลด https://github.com/Cms2u/GenClip-release/raw/main/GenClip.zip แล้วแตกไฟล์ไว้ที่ที่จะไม่ลบ เช่น `C:\GenClip`
2. `chrome://extensions` → เปิดโหมดนักพัฒนาซอฟต์แวร์ → โหลดส่วนขยายที่แตกไฟล์แล้ว → เลือกโฟลเดอร์ `GenClip`
3. กด "รายละเอียด" ของ GenClip → เปิด "อนุญาตให้เข้าถึง URL ของไฟล์"

**อัปเดต:** เมื่อมีเวอร์ชันใหม่ ด้านบนของแผง GenClip จะขึ้น "มีอัปเดตระบบใหม่" กดปุ่ม **อัปเดต** ครั้งแรกระบบจะให้เลือกโฟลเดอร์ `GenClip` ที่แตกไว้ (กดอนุญาตแก้ไขไฟล์) ครั้งต่อไปกดปุ่มเดียวจบ ระบบดาวน์โหลด เขียนทับ และรีโหลดเอง

ผู้พัฒนา: หลัง commit เวอร์ชันใหม่ รัน `bash tools/release.sh` เพื่อส่งขึ้น repo สาธารณะ `Cms2u/GenClip-release`

## ใช้ในทีม แบบ git (ติดตั้งและอัปเดต)
โค้ดอยู่ใน GitHub repo แบบ private ทุกเครื่องในทีมจะอัปเดตตามเวอร์ชันล่าสุดเอง

**ติดตั้งครั้งแรก (ทำครั้งเดียวต่อเครื่อง)**
1. เจ้าของ repo เชิญบัญชี GitHub ของคนในทีมเข้า repo (Settings → Collaborators)
2. คนในทีมดาวน์โหลดไฟล์ `tools/setup-team.bat` แล้วดับเบิลคลิก ระบบจะ
   - ติดตั้ง Git ให้ ถ้ายังไม่มี (เสร็จแล้วให้ดับเบิลคลิกไฟล์นี้อีกครั้ง)
   - ดาวน์โหลด GenClip ไปที่ `%USERPROFILE%\GenClip` ถ้ามีหน้าต่างให้ล็อกอิน GitHub ให้ล็อกอินด้วยบัญชีที่ได้รับเชิญ
   - ตั้งงานตั้งเวลา "GenClip Auto Update" ให้ดึงเวอร์ชันใหม่ทุก 30 นาที แบบเงียบ ๆ
3. ที่ `chrome://extensions` เปิดโหมดนักพัฒนา → **โหลดส่วนขยายที่คลายการบีบอัด** → เลือกโฟลเดอร์ `GenClip` → กด **รายละเอียด** → เปิด **อนุญาตให้เข้าถึง URL ของไฟล์**

**เมื่อมีเวอร์ชันใหม่**
- **ปกติ:** ภายใน 30 นาที side panel จะขึ้นแถบ **"มีเวอร์ชันใหม่ vX"** ให้กด **"รีโหลด GenClip"** ถ้ากำลังทำงานอยู่ ให้รอเสร็จก่อน
- **อยากได้ทันที:** ดับเบิลคลิก `tools/update-now.bat` แล้วกดรีโหลด

**สำหรับผู้พัฒนา:** แก้โค้ดที่เครื่องหลัก เพิ่มเลข `version` ใน `manifest.json` ทุกครั้ง แล้ว commit และ push ขึ้น GitHub ห้ามแก้ไฟล์ในโฟลเดอร์ GenClip บนเครื่องของคนในทีม เพราะจะทำให้อัปเดตอัตโนมัติไม่ได้

## ข้อควรรู้
- ระบบนี้ควบคุมหน้าเว็บแทนการใช้ API จึงอาจพังได้เมื่อ ChatGPT หรือ Flow อัปเดตหน้าเว็บ และอาจขัดเงื่อนไขการใช้งาน (ToS) ของ OpenAI และ Google ควรใช้ในปริมาณพอเหมาะ อย่ารันรัว ๆ ทั้งวัน
- ตรวจทุกคลิปก่อนโพสต์ว่า **ลายผ้าและสีตรงกับสินค้าจริง** เพื่อไม่ให้ลูกค้าได้ของไม่ตรงปก
- TikTok, Facebook และ Shopee กำหนดให้ **ติดป้ายเนื้อหาที่สร้างด้วย AI** และห้ามนำคลิปไปเปิดเป็นไลฟ์สด
